"The Ultimate NFL Stadium Roadtrip Bucketlist

My Idea:
This app will be for the ultimate NFL Fan who enjoys football and travel. The app will render a page for each NFL Stadium. The user will be able to add an image of themselves in or with the stadium, record the game score, note how many miles they traveled to see the game, and describe their experience including concessions and souvenirs purchased. So, to sum it up, it will be a keepsake-style checklist/scrapbook for users to document their visits to each stadium with pictures and notes about their experiences. This is a very basic version of an application idea that I would eventually work on when I have more experience.

MVP:
At first glance, I feel like this project will involve a lot of repetitive steps that will utilize what I have learned so far in HTML, CSS, JavaScript, and React. Keeping in mind not to dive too deep and make this app too complex, I want to ensure that I can produce an MVP that will utilize API databases, CRUD methods, as well as props, context, and routers. The overall nature of this project, I feel, will help me become more familiar with the syntax and conventions of what I have learned so far while producing a simple yet enjoyable app for avid football fans. I estimate 4-5 days for completion.

User Stories:
Until I can learn how a user can create an "account" so that all their info will be saved for their next visit, the user will go to the site/app's homepage and select the stadium they have just visited. Once they are on the Stadiums page, the user will be able to submit images, scores, and details of their experience. The user will continue to do this until they have completed the RoadTrip Bucketlist.

Wireframe:
The layout will be simple. The home page will list the stadiums with a thumbnail-sized image of the stadium or team logo (I haven't decided yet). Each Stadium page will display both the logo and stadium images, be themed and styled to the colors of that team, and include a form input that will allow the user to post images and text, giving it a "scrapbook" look to their experience.

Mind Map:
The structure of the application, I think, will only be a few levels deep. I'm picturing a main home page, with each team as a child of that home page. The form will be a component that will render to each child of the home page. And then the user-submitted data will be a component itself to render to each child of the component."
